# 🇸🇦 Saudi Vision 2030 KPI Dashboard — Power BI

## 📊 Project Overview

This project presents an interactive **Power BI dashboard** designed to visualise and track key performance indicators (KPIs) related to **Saudi Vision 2030**.

The dashboard provides a data-driven view of KPI performance across different areas, allowing users to explore the available indicators by **year, quarter, month, and KPI**.

The project demonstrates practical skills in **Power BI, data visualisation, KPI analysis, dashboard design, and business intelligence**. 
## The dataset is taken from the https://vision2030.ai/data/ website.

---

## 🎯 Project Objectives

The main objectives of this project are to:

* Analyse Saudi Vision 2030 KPI data.

## 📊 Dashboard Structure

The dashboard contains several visual components, including:

### KPI Overview

Provides an overall view of the number of KPIs available in the dataset.

### Year & Quarter Analysis

Interactive filters allow users to select:

* Year
* Quarter
* KPI

This makes it possible to analyse KPI information for different reporting periods.

### Current vs Target Analysis

A comparison between the **current KPI values** and their **2030 target values** provides a simple way to understand progress towards the defined targets.

### KPI Status

The dashboard includes a KPI status view showing the distribution of KPI statuses within the dataset.
